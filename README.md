# Hoang Quoc Viet — Portfolio

Personal portfolio built with plain HTML, CSS, and JavaScript.

Website: https://hqvz28.github.io/

## Local preview

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. The page includes English/Vietnamese content,
light/dark themes, expandable architecture diagrams, and print-to-PDF styling.

## Deployment

GitHub Pages serves `index.html` from the root of the `main` branch.
Push changes to `main` to publish an update.
